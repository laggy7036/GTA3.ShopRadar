# Security and privacy

The mod has no network feature, account login, telemetry or credential requirement. It reads game state to draw markers and writes its own settings/log beside the ASI. It does not write saves.

Before reporting a bug, share only the information needed to reproduce it: executable variant, mod version, loader/other mod names and steps. Do not upload personal saves, credentials, full memory dumps or unreviewed desktop captures. Review logs for personal information before sharing.

Report a sensitive issue through GitHub's private vulnerability reporting if enabled. Do not put credentials or personal data in a public issue.

The offline publication checker detects a defined set of suspicious files and patterns. It does not provide a guarantee against every possible disclosure.
